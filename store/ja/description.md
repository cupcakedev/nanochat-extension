NanoChatは、Google Chromeでローカルに動作するプライベートなAIサイドバーです。閲覧中のページの横で開き、質問、記事の要約、文章の解説、選択したテキストの書き換えを行えます。ページの内容を別のチャットへコピーする必要はありません。

ブラウザでの読書、リサーチ、執筆、生産性向上のために設計されたNanoChatは、Webページに関するチャットと、ユーザーが管理するAIブラウザエージェントを組み合わせます。Chrome内蔵のPrompt APIとGemini Nanoを使用するため、APIキー、アカウント、サブスクリプション、外部AIサービスは不要です。

NanoChatでできること：
- 専用AIサイドパネルで、現在のWebページやドキュメントについてチャット
- 右クリックメニューから記事の要約、難しい箇所の解説、選択範囲の翻訳、文章の書き換え、スペルチェック
- 対応デバイスで、画像やスクリーンショットを添付したマルチモーダルなプロンプト
- 実験的なブラウザエージェントで、クリック、入力、スクロール、ページ移動などの見える操作を実行
- 検索可能な会話履歴を拡張機能内にローカル保存
- キーボードショートカットでAIアシスタントをすばやく開く

プライバシーを重視した設計：
- NanoChatは、プロンプト、ページのコンテキスト、会話内容を外部AIサービスへ送信しません
- チャットは拡張機能内にローカル保存されます
- エージェントのすべての操作は表示され、ユーザーの管理下にあります

学生、研究者、ライター、専門職の方、クラウド型チャットツールよりローカルAIを選びたい方に最適です。Chromeの内蔵AI機能を試す方法としても便利です。

動作要件：
- Prompt APIとGemini Nanoに対応したデスクトップ版Google Chrome
- Chromeの最新オンデバイスAI要件を満たすデバイス。現在はモデル用に22 GB以上の空き容量と、十分なCPUまたはGPUリソースが必要です
- 使用前にChromeで内蔵AIモデルが利用可能、またはダウンロード済みであること
