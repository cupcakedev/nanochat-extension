Un assistant IA local et gratuit pour Chrome, qui s'exécute sur votre appareil. Le modèle tourne directement dans le navigateur : vos requêtes, le contenu des pages et vos conversations ne quittent jamais votre ordinateur — sans clé d'API, sans compte, sans abonnement ni service d'IA externe.

NanoChat s'ouvre dans le panneau latéral de Chrome, à côté de la page que vous lisez. Posez des questions sur la page en cours, résumez un article, faites expliquer un passage, réécrivez le texte sélectionné ou travaillez à partir du contexte de la page sans le copier dans un chat séparé. Le tout repose sur la Prompt API intégrée de Chrome et Gemini Nano.

Pourquoi une IA sur l'appareil :
- Vos requêtes, le contexte des pages et vos conversations ne sont jamais envoyés à un service d'IA externe
- Fonctionne sans connexion, sans compte et sans clé d'API
- Les conversations sont stockées localement dans l'extension
- Aucun coût par message et aucun quota d'usage cloud
- Utilisable sur des pages au contenu interne ou sensible

Ce que vous pouvez faire :
- Discuter avec la page web ou le document en cours dans un panneau latéral IA dédié
- Résumer des articles, expliquer des passages complexes, traduire une sélection, réécrire un texte et vérifier l'orthographe depuis le menu contextuel
- Joindre des images et des captures d'écran pour des prompts multimodaux sur les appareils compatibles
- Laisser l'agent de navigation expérimental proposer et exécuter des actions sur la page : clics, saisie, défilement et navigation — chaque action reste visible et sous votre contrôle
- Conserver un historique local de vos conversations, avec recherche
- Ouvrir l'assistant IA instantanément grâce à un raccourci clavier (Ctrl+Maj+Y, ou Command+Maj+Y sur macOS)

Pour qui :
- Étudiants et chercheurs qui veulent comprendre et résumer plus vite le contenu web
- Rédacteurs et professionnels qui ont besoin d'un assistant IA à côté de leur page de travail
- Utilisateurs soucieux de leur vie privée qui préfèrent une IA locale aux chats dans le cloud
- Développeurs qui explorent l'IA intégrée sur l'appareil dans Chrome

Prérequis :
- Une version de bureau de Google Chrome compatible avec la Prompt API intégrée et Gemini Nano
- Un appareil conforme aux exigences de Chrome pour l'IA locale : actuellement au moins 22 Go d'espace libre pour le modèle et des ressources CPU ou GPU suffisantes
- Le modèle d'IA intégré doit être disponible ou téléchargé dans Chrome avant la première utilisation

NanoChat est gratuit et open source : https://github.com/cupcakedev/nanochat-extension
