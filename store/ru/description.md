Бесплатный локальный AI-ассистент для Chrome, который работает на вашем устройстве. Модель запускается прямо в браузере, поэтому запросы, содержимое страниц и переписка не покидают компьютер — без API-ключа, аккаунта, подписки и внешнего ИИ-сервиса.

NanoChat открывается в боковой панели Chrome рядом с текущей вкладкой. Задайте вопрос по странице, кратко перескажите статью, объясните фрагмент, перепишите выделенный текст или работайте с контекстом страницы, не копируя его в отдельный чат. Расширение использует встроенный Prompt API Chrome и Gemini Nano.

Почему локальная модель:
- Запросы, контекст страницы и диалоги не отправляются во внешний ИИ-сервис
- Не нужны аккаунт, вход и API-ключ
- История диалогов хранится локально в расширении
- Нет оплаты за сообщения и облачных лимитов
- Можно использовать на страницах с внутренним или чувствительным содержимым

Что умеет NanoChat:
- Чат по содержимому текущей веб-страницы или документа в отдельной боковой панели
- Суммаризация статей, объяснение сложных фрагментов, перевод выделенного текста, рерайт и проверка орфографии через контекстное меню
- Изображения и скриншоты для мультимодальных запросов на поддерживаемых устройствах
- Экспериментальный агент браузера: клики, ввод текста, прокрутка и переходы — каждое действие видимо и остаётся под вашим контролем
- Локальная история диалогов с поиском по чатам
- Быстрый вызов ассистента сочетанием клавиш (Ctrl+Shift+Y, на macOS — Command+Shift+Y)

Кому подойдёт:
- Студентам и исследователям, которым нужно быстрее понимать и суммаризировать веб-контент
- Авторам и специалистам, которым нужен AI-ассистент прямо рядом с рабочей страницей
- Тем, кто ценит приватность и предпочитает локальный ИИ облачным чат-сервисам
- Разработчикам, изучающим встроенный ИИ в Chrome

Требования:
- Десктопная версия Google Chrome с поддержкой встроенного Prompt API и Gemini Nano
- Устройство, отвечающее требованиям Chrome к локальному ИИ: сейчас это минимум 22 ГБ свободного места под модель и достаточные ресурсы CPU или GPU
- Встроенная модель должна быть доступна или загружена в Chrome до первого использования
