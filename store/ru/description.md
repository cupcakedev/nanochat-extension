NanoChat — приватный локальный ИИ-ассистент в боковой панели Google Chrome. Откройте его рядом с текущей вкладкой, чтобы задать вопрос по странице, кратко пересказать статью, объяснить фрагмент, переписать выделенный текст или работать с контекстом страницы без копирования в отдельный чат.

NanoChat создан для чтения, исследований, письма и продуктивной работы в браузере. Он сочетает чат по веб-странице с управляемым пользователем ИИ-агентом браузера и работает через встроенный Prompt API Chrome и Gemini Nano — без API-ключа, аккаунта, подписки и внешнего ИИ-сервиса.

Что умеет NanoChat:
- Общаться по содержимому текущей веб-страницы или документа в отдельной боковой панели ИИ
- Суммаризировать статьи, объяснять сложные фрагменты, переводить выделенный текст, переписывать текст и проверять орфографию через контекстное меню
- Принимать изображения и скриншоты для мультимодальных запросов на поддерживаемых устройствах
- В экспериментальном режиме агента выполнять действия на странице: кликать, вводить текст, прокручивать и переходить по страницам
- Хранить историю диалогов локально и быстро находить прошлые чаты поиском
- Быстро открываться с помощью сочетания клавиш

Приватность по умолчанию:
- NanoChat не отправляет ваши запросы, контекст страницы и диалоги во внешний ИИ-сервис
- Диалоги хранятся локально в расширении
- Все действия ИИ-агента видимы и остаются под вашим контролем

Кому подойдет:
- Студентам и исследователям, которым нужно быстрее понимать и суммаризировать веб-контент
- Авторам и специалистам, которым нужен ИИ-ассистент прямо рядом с рабочей страницей
- Пользователям, выбирающим локальный ИИ вместо облачных чат-ботов
- Разработчикам, изучающим встроенные ИИ-возможности Chrome

Требования:
- Настольная версия Google Chrome с поддержкой Prompt API и Gemini Nano
- Устройство, соответствующее актуальным требованиям Chrome для встроенного ИИ; сейчас Chrome требует не менее 22 ГБ свободного места для модели и достаточные ресурсы CPU или GPU
- Встроенная ИИ-модель должна быть доступна или загружена в Chrome до начала работы
