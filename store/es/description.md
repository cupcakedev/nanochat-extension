NanoChat: Asistente de IA local y Agente web es una extensión de navegador para personas que desean un asistente de IA privado, seguro y completamente local. Chatea con cualquier página web, automatiza acciones en pantalla con el Agente de IA, procesa instantáneamente el texto seleccionado y resume artículos sin que ningún dato salga de tu dispositivo.

Ya sea que uses NanoChat para aprender, trabajar, investigar o para la productividad, NanoChat te ayuda a resumir información más rápido y te brinda control directo sobre tus flujos de trabajo de IA locales. Tú eliges qué acciones ejecutar y cómo interactuar con tus páginas.

Características clave:
- Chatea con la IA sobre cualquier página web o documento que estés viendo
- Agente de IA de navegador: permite que la IA haga clic, escriba, se desplace y navegue por las páginas en tu lugar
- Menú contextual inteligente: selecciona texto para Traducir (Translate), Resumir (Summarize), Reescribir (Rewrite), Corrección ortográfica (Spellcheck) o Explicar (Explain)
- Adjunta imágenes o capturas de pantalla directamente a tus mensajes para una entrada multimodal
- Historial completo de conversaciones con búsqueda para recuperar rápidamente chats pasados
- Funciona a la perfección en cualquier página web de tu pestaña activa
- Arquitectura que prioriza la privacidad, impulsada por Gemini Nano de Chrome integrado (Prompt API)
- Configuración cero: instala y comienza a chatear localmente sin claves API ni configuraciones complejas

Por qué los usuarios eligen NanoChat:
- 100% privado: sin API en la nube, no se envían datos a servidores externos
- Capacidad sin conexión: se ejecuta completamente en el dispositivo a través de tu navegador
- Accesibilidad instantánea: cómodo diseño de panel lateral
- Automatización web interactiva con modo Agente experimental
- Completamente gratis y de código abierto, sin registros ni suscripciones

Ideal para:
- Usuarios que valoran la privacidad de los datos y desean mantener las conversaciones de forma local
- Profesionales y estudiantes que necesitan leer, resumir o analizar contenido web
- Desarrolladores y entusiastas de la tecnología que exploran las capacidades de IA local nativa de Chrome
- Cualquier persona que busque un copiloto de IA local y sin distracciones dentro del navegador

Requisitos importantes:
Para ejecutar NanoChat localmente, tu sistema y navegador deben cumplir con lo siguiente:
- Versión de Chrome 138 o superior
- GPU: al menos 4 GB de VRAM
- CPU/RAM: mínimo 4 núcleos de CPU y 16 GB de RAM
- Flags de IA integrada habilitadas en Chrome (consulta el repositorio de GitHub para obtener detalles de configuración)

NanoChat es de código abierto: https://github.com/cupcakedev/nanochat-extension
