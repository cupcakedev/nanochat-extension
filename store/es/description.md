NanoChat es una barra lateral de IA privada y local para Google Chrome. Ábrela junto a la página que estás leyendo para hacer preguntas, resumir un artículo, explicar un fragmento, reescribir texto seleccionado o trabajar con el contexto de la página sin copiarlo a otro chat.

Creado para lectura, investigación, redacción y productividad en el navegador, NanoChat combina el chat con páginas web y un agente de navegador de IA controlado por ti. Funciona con la Prompt API integrada de Chrome y Gemini Nano: no necesitas claves API, cuenta, suscripción ni un servicio de IA externo.

Qué puedes hacer con NanoChat:
- Chatear sobre la página web o el documento actual en un panel lateral de IA dedicado
- Resumir artículos, explicar pasajes complejos, traducir selecciones, reescribir texto y revisar la ortografía desde el menú contextual
- Adjuntar imágenes y capturas de pantalla para prompts multimodales en dispositivos compatibles
- Usar el agente de navegador experimental para realizar acciones visibles: hacer clic, escribir, desplazarse y navegar
- Conservar un historial local de conversaciones con búsqueda
- Abrir el asistente de IA rápidamente con un atajo de teclado

Privacidad por diseño:
- NanoChat no envía tus prompts, el contexto de la página ni tus conversaciones a un servicio de IA externo
- Los chats se almacenan localmente en la extensión
- Todas las acciones del agente permanecen visibles y bajo tu control

Ideal para estudiantes, investigadores, escritores, profesionales y personas que prefieren la IA local a las herramientas de chat en la nube. También es una forma práctica de explorar las capacidades de IA integradas en Chrome.

Requisitos:
- Google Chrome para escritorio compatible con Prompt API y Gemini Nano
- Un dispositivo que cumpla los requisitos actuales de IA en el dispositivo de Chrome; actualmente se necesitan al menos 22 GB de espacio libre para el modelo y recursos de CPU o GPU suficientes
- El modelo de IA integrado debe estar disponible o descargarse en Chrome antes de usarlo

NanoChat es gratuito y de código abierto: https://github.com/cupcakedev/nanochat-extension
