在你的设备上运行的免费本地 AI 助手。模型直接在浏览器中运行，你的提问、网页内容和聊天记录都不会离开电脑——无需 API 密钥、账号、订阅，也不依赖任何外部 AI 服务。

NanoChat 在 Chrome 侧边栏中打开，就在你正在阅读的网页旁边。你可以就当前页面提问、总结文章、请它解释某个段落、改写选中的文字，或者直接基于页面内容工作，而不必把内容复制到另一个聊天窗口。它基于 Chrome 内置的 Prompt API 和 Gemini Nano 运行。

为什么选择设备端 AI：
- 提问内容、页面上下文和对话记录不会发送到外部 AI 服务
- 无需登录、账号或 API 密钥
- 聊天记录保存在扩展本地
- 没有按条计费，也没有云端用量额度
- 可以在包含内部资料或敏感内容的页面上使用

你可以做什么：
- 在专属的 AI 侧边栏中与当前网页或文档对话
- 通过右键菜单总结文章、解释复杂段落、翻译选中内容、改写文案和检查拼写
- 在支持的设备上附加图片和截图，进行多模态提问
- 让实验性浏览器智能体提出并执行页面操作，如点击、输入、滚动和跳转——每一步操作都可见且由你掌控
- 在本地保存可搜索的对话历史
- 用快捷键即时打开 AI 助手（Ctrl+Shift+Y，macOS 为 Command+Shift+Y）

适合谁使用：
- 希望更快理解和总结网页内容的学生与研究人员
- 需要 AI 助手就在工作页面旁边的写作者和职场人士
- 更愿意使用本地 AI 而非云端聊天工具的隐私敏感用户
- 想要探索 Chrome 内置设备端 AI 的开发者

使用要求：
- 支持内置 Prompt API 和 Gemini Nano 的桌面版 Google Chrome
- 满足 Chrome 本地 AI 要求的设备：目前需要至少 22 GB 可用磁盘空间存放模型，以及足够的 CPU 或 GPU 资源
- 首次使用前，内置 AI 模型需在 Chrome 中可用或已下载完成
