NanoChat 是一款在 Google Chrome 中本地运行的私密 AI 侧边栏助手。将它打开在当前网页旁边，即可提问、总结文章、解释段落、改写选中文本，或直接利用网页上下文，无需复制到另一个聊天工具。

NanoChat 专为浏览器中的阅读、研究、写作和效率提升而打造，结合网页对话与由您控制的 AI 浏览器 Agent。它使用 Chrome 内置的 Prompt API 和 Gemini Nano，因此不需要 API 密钥、账号、订阅或外部 AI 服务。

NanoChat 可以帮您：
- 在专用 AI 侧边栏中围绕当前网页或文档对话
- 通过右键菜单总结文章、解释复杂段落、翻译选中文本、改写文案和检查拼写
- 在受支持的设备上附加图片和屏幕截图，进行多模态提示
- 使用实验性的浏览器 Agent 执行可见操作，例如点击、输入、滚动和页面导航
- 将可搜索的对话历史保存在扩展程序本地
- 通过键盘快捷键快速打开 AI 助手

隐私优先：
- NanoChat 不会将您的提示、网页上下文或对话发送到外部 AI 服务
- 聊天记录仅保存在扩展程序本地
- Agent 的每一项操作都保持可见，并由您掌控

它适合学生、研究人员、写作者、专业人士，以及所有希望使用本地 AI 而非云端聊天工具的用户，也是探索 Chrome 内置 AI 功能的实用方式。

使用要求：
- 支持 Prompt API 和 Gemini Nano 的桌面版 Google Chrome
- 满足 Chrome 当前设备端 AI 要求的设备；目前模型至少需要 22 GB 可用空间，以及足够的 CPU 或 GPU 资源
- 使用前，Chrome 内置 AI 模型必须已可用或完成下载
