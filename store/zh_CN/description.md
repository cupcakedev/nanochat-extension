NanoChat: 本地 AI 侧边栏与浏览器 Agent 是一款专为追求隐私、安全及完全本地化运行 AI 助手的人群设计的浏览器扩展。您可以与任何网页进行对话、通过 AI Agent 自动执行页面操作、即时处理所选文本以及总结文章，所有数据绝不离开您的设备。

无论您是将 NanoChat 用于学习、工作、研究还是提升效率，NanoChat 都能帮您更快地提炼信息，并让您对本地 AI 工作流拥有直接的控制权。您可以自由选择执行哪些操作以及如何与页面进行交互。

核心功能：
- 围绕您正在浏览的任何网页或文档与 AI 进行对话
- AI 浏览器 Agent：让 AI 代替您进行点击、输入、滚动及网页导航
- 智能右键上下文菜单：选中文本即可即时进行翻译 (Translate)、总结 (Summarize)、重写 (Rewrite)、拼写检查 (Spellcheck) 或解释说明 (Explain)
- 支持直接在消息中附加图片或屏幕截图，进行多模态输入分析
- 提供完整的对话历史记录及搜索功能，快速找回过往聊天内容
- 在您当前活动浏览器标签页的任何网页上都能无缝工作
- 隐私第一的架构设计，完全由 Chrome 内置的 Gemini Nano (Prompt API) 驱动
- 零配置：即装即用，无需 API 密钥或复杂的设置即可在本地开启对话

为什么用户选择 NanoChat：
- 100% 保护隐私：无云端 API，不向外部服务器发送任何数据
- 离线运行能力：通过您的浏览器完全在本地设备上运行
- 即时访问：便捷的侧边栏 (Side Panel) 布局
- 交互式网页自动化，配备实验性的 Agent 模式
- 完全免费且开源，无注册或订阅要求

非常适合：
- 重视数据隐私、希望将所有对话保存在本地的用户
- 需要阅读、总结或分析网页内容的专业人士和学生
- 想要体验 Chrome 原生本地 AI 能力的开发者及科技爱好者
- 任何在寻找无干扰、本地浏览器 AI 助手的人

重要运行要求：
要在本地运行 NanoChat，您的系统 and 浏览器需要满足以下条件：
- Chrome 浏览器版本 138 或更高
- 显卡 (GPU)：至少 4 GB 显存 (VRAM)
- 处理器与内存 (CPU/RAM)：至少 4 核 CPU 以及 16 GB 内存
- Chrome 中已启用内置 AI 相关 Flags（设置详情请参阅 GitHub 仓库）

NanoChat 已开源：https://github.com/cupcakedev/nanochat-extension
